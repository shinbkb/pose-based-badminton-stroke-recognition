# Mở báo cáo trên Overleaf

## Cách nhanh nhất

1. Vào https://www.overleaf.com/project.
2. Chọn **New Project → Upload Project**.
3. Tải file `overleaf-progress-report.zip` lên.
4. Nếu Overleaf chưa chọn đúng file chính, vào **Menu → Main document** và chọn `progress_report.tex`.
5. Vào **Menu → Compiler** và chọn **XeLaTeX**.
6. Nhấn **Recompile**.

## Nội dung gói

- `progress_report.tex`: mã nguồn báo cáo.
- `figures/`: bốn biểu đồ kết quả được báo cáo sử dụng.

Trước khi nộp, sửa các lệnh thông tin ở đầu `progress_report.tex`: tên trường, khoa, MSSV, lớp và giảng viên hướng dẫn.
